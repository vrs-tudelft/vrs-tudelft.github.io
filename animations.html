Animations

Two players, 36 frames each, one frame per eighth satellite pass. Use the buttons under each one to play, pause, step, or change the speed.

The scene, pass by pass

Every point coloured by how much it moved since the previous pass, 11 days earlier. The colour scale is fixed for all frames and symmetric around zero, so a calm pass looks calm. Ten years of slow sinking are differenced away; what remains is air and noise.

The height regression, pass by pass

Top: displacement against height above ground for 2 500 points, with the fitted line for that pass. Bottom: the slope of that line over the full ten years, with a marker following the frame. The tilt above and the curve below are the same thing.

Both animations are made with matplotlib from the team code and saved as self-contained pages, so they need no server and no plugins.

TerraSAR-X point set provided for the course by R.F. Hanssen. Virtual Radiosonde, TU Delft, 2026.
